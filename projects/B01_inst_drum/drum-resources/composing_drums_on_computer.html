Composing Drums on a Computer: DAW & Code

Applying the Four Dimensions to Produce High-Quality Drum Tracks

This document bridges the theory from the Four Dimensions framework to the practice of producing drums on a computer. It covers two approaches:

  1. DAW Workflow: Manual composition in a Digital Audio Workstation.
  2. Coding Workflow: Programmatic generation using Python.

Part 1: The DAW Workflow​

The Trap: Quantization​

The single biggest mistake in programmed drums is perfect quantization. When every hit lands exactly on the grid with the exact same velocity, the result sounds robotic and lifeless. Your goal is to use the grid as a guide, not a law.

The 4-Dimension Lens: A perfectly quantized beat has Dimension 1 (Grid) mastered, but Dimension 2 (Feel), Dimension 3 (Interplay), and Dimension 4 (Narrative) are completely absent.

Core Principles for DAW Drum Production​

1. Master Velocity (Dimension 4: Dynamics)​

MIDI velocity is a number from 0-127 representing how hard a note is struck. Never leave all hits at the same velocity.

Drum PieceVelocity Strategy
KickKeep relatively consistent (90-110) to anchor the groove. May increase slightly in choruses.
Snare (Backbeat)Should be the loudest hits (100-120). These are beats 2 and 4.
Snare (Ghost Notes)Very soft (20-50). These fill the space between main hits.
Hi-Hat (Closed)Alternate velocity: Downbeats slightly louder (80-95), upbeats softer (60-75).
Hi-Hat (Open)Louder than closed (90-110) to cut through. Usually on "ands."
CrashFull velocity (110-127) on downbeat of new section (chorus, bridge).

DAW Tip: Select all your snare ghost notes and use the "Compress Velocity" function to bring them into a tight, low range.

2. Introduce Micro-Timing (Dimension 2: Feel)​

Slightly shift notes off the grid to create a human feel.

TechniqueHow To Do ItEffect
Lay Back the SnareNudge snare hits on beats 2 and 4 by +5 to +15 ms (ahead in time).Creates a heavy, relaxed groove (Hip-Hop, Blues).
Push the Hi-HatsNudge hi-hat hits by -5 to -10 ms (earlier).Creates a driving, urgent feel (Punk, Rock).
Apply SwingUse your DAW's "Swing" or "Groove" function (try 54-60%).Delays every other 8th or 16th note, creating a shuffle or bounce.
Randomize (Subtly)Apply timing randomization of ±10 ms maximum.Adds general human imperfection.

DAW Tip: Most DAWs (Ableton, Logic, FL Studio) have a "Humanize" function. Start with small values (5-10%) and increase by ear.

3. Think Like a Drummer (Physical Realism)​

Drummers have two hands and two feet. Your patterns must respect this.

  • The Sticking Test: Air-drum your pattern. If your hands have to teleport across the kit, it's unrealistic.
  • Hi-Hat Foot Rule: If the hi-hat is playing consistently, the left foot is occupied. The drummer cannot play the kick with their left foot at the same time (on a standard kit).
  • Crash + Kick: Crashes almost always land with the kick drum on beat 1 of a new section.
  • Open/Closed Hi-Hat Choking: An open hi-hat must be "choked" (stopped) when a closed hi-hat follows. Your sampler/drum plugin should handle this, but verify it.

4. Program a Dynamic Arc (Dimension 4: Narrative)​

A song should breathe. Map out the dynamics before you program.

Intro:  [Low]   - Hat + Kick only, low velocity.
Verse 1: [Medium] - Full beat, moderate velocity.
Chorus: [High]  - Full beat, high velocity, crashes on 1.
Verse 2: [Medium-Low] - Pull back, maybe half-time feel or no crash.
Bridge: [Different] - New texture (toms only? rim click? brushes?).
Outro:  [Fade]  - Decrescendo.

DAW Tip: Use automation lanes to control the overall velocity of the drum group over time.

Workflow: Building a Beat Step-by-Step​

  1. Lay the Foundation: Program the Kick and Snare backbeat. Quantize to the grid. Get the pattern right first.
  2. Add Hi-Hats: Add 8th or 16th note hi-hats. Start with consistent velocity.
  3. Humanize Velocity: Adjust hi-hat velocities (downbeats louder). Add ghost notes to snare (very low velocity).
  4. Humanize Timing: Apply subtle timing shifts. Nudge snare slightly late. Consider swing.
  5. Add Ear Candy: Open hi-hats, crashes at section changes, fills before choruses.
  6. A/B Test: Listen to your beat against a reference track (a song with drums you admire). Compare the "feel."

Part 2: The Coding Workflow (Python)​

Coding drums is powerful for generative music, precise control, and algorithmic experimentation.

Libraries​

pip install pretty_midi numpy

The General MIDI Drum Map​

In MIDI, Channel 10 is reserved for drums. Each pitch number corresponds to a specific drum sound.

PitchDrum Sound
36Kick Drum
38Snare Drum
37Side Stick / Rim Click
40Snare (Ghost Note / Lighter Sound)
42Closed Hi-Hat
44Hi-Hat Pedal (Foot Chick)
46Open Hi-Hat
49Crash Cymbal 1
51Ride Cymbal
41, 43, 45, 47, 48, 50Toms (Low to High)

Starter Code: A Basic Rock Beat with Humanization​

This code generates a standard 8th-note rock beat with velocity variation and micro-timing.

import pretty_midi
import numpy as np
import random

# --- Config ---
BPM = 100
BEATS_PER_BAR = 4
NUM_BARS = 4
OUTPUT_FILE = "my_drum_beat.mid"

# --- Drum Map (GM Standard) ---
KICK = 36
SNARE = 38
CLOSED_HAT = 42

# --- Helper Functions ---
def beats_to_seconds(beat, bpm):
    """Converts beat number to time in seconds."""
    return beat * (60.0 / bpm)

def add_note(instrument, pitch, start_beat, bpm, velocity, duration_beats=0.1, offset_ms=0):
    """
    Adds a note to a MIDI instrument with humanization.
    offset_ms: Micro-timing shift in milliseconds. Positive = later (behind beat).
    """
    start_time = beats_to_seconds(start_beat, bpm) + (offset_ms / 1000.0)
    end_time = start_time + beats_to_seconds(duration_beats, bpm)
    note = pretty_midi.Note(velocity=int(velocity), pitch=pitch, start=start_time, end=end_time)
    instrument.notes.append(note)

# --- Create MIDI Object ---
midi = pretty_midi.PrettyMIDI(initial_tempo=BPM)
drums = pretty_midi.Instrument(program=0, is_drum=True, name="Drums")

# --- Generate Pattern ---
total_beats = BEATS_PER_BAR * NUM_BARS

for beat in np.arange(0, total_beats, 0.5): # 8th notes
    current_beat_in_bar = beat % BEATS_PER_BAR

    # --- Kick on 1 and 3 ---
    if current_beat_in_bar == 0 or current_beat_in_bar == 2:
        kick_velocity = random.randint(95, 110)
        add_note(drums, KICK, beat, BPM, kick_velocity)

    # --- Snare on 2 and 4 (with slight lay-back) ---
    if current_beat_in_bar == 1 or current_beat_in_bar == 3:
        snare_velocity = random.randint(100, 115)
        snare_offset = random.uniform(8, 15) # 8-15ms BEHIND the beat
        add_note(drums, SNARE, beat, BPM, snare_velocity, offset_ms=snare_offset)

    # --- Hi-Hat on every 8th note ---
    # Downbeats (0, 1, 2, 3) are louder than upbeats (0.5, 1.5, etc.)
    is_downbeat = (beat % 1 == 0)
    if is_downbeat:
        hat_velocity = random.randint(80, 95)
    else:
        hat_velocity = random.randint(55, 70)
    
    hat_offset = random.uniform(-5, 5) # Small random timing variation
    add_note(drums, CLOSED_HAT, beat, BPM, hat_velocity, offset_ms=hat_offset)

# --- Write to File ---
midi.instruments.append(drums)
midi.write(OUTPUT_FILE)
print(f"MIDI file saved to: {OUTPUT_FILE}")

Advanced: Adding Ghost Notes​

# Add this inside the beat loop, after the snare section

# --- Ghost Notes on 16th notes (e's and a's) ---
# Check for 16th note positions that are NOT on the 8th note grid
for sub_beat_offset in [0.25, 0.75]: # The "e" and "a" of each beat
    ghost_beat = beat + sub_beat_offset
    if ghost_beat < total_beats:
        # Only add ghost note some of the time (e.g., 40% chance)
        if random.random() < 0.40:
            ghost_velocity = random.randint(25, 45) # Very soft
            ghost_offset = random.uniform(-10, 10)
            add_note(drums, SNARE, ghost_beat, BPM, ghost_velocity, offset_ms=ghost_offset)

Advanced: Generating a Fill​

A fill typically replaces the last beat or two of a bar, often moving down the toms.

# --- Add a fill at the end of bar 4 ---
TOMS = [50, 48, 47, 45, 43, 41] # High tom to floor tom

fill_start_beat = (NUM_BARS - 1) * BEATS_PER_BAR + 2.5 # Start on "and of 3"
fill_notes = [0, 0.25, 0.5, 0.75, 1.0, 1.25] # 16th note rhythm

for i, note_offset in enumerate(fill_notes):
    fill_beat = fill_start_beat + note_offset
    if fill_beat < total_beats:
        # Select tom: start high, go low
        tom_pitch = TOMS[min(i, len(TOMS) - 1)]
        
        # Velocity: crescendo into beat 1
        fill_velocity = 70 + (i * 8) # Gets louder
        
        add_note(drums, tom_pitch, fill_beat, BPM, fill_velocity)

# You would also want to REMOVE the hat notes that overlap with the fill.

Part 3: Cheat Sheet (Combining Both Worlds)​

DimensionDAW TechniqueCode Implementation
1. GridUse "Quantize" as a starting point, not an end.Define notes at exact beat positions first.
2. FeelNudge notes + Swing. Use "Humanize."Add offset_ms parameter with controlled randomness or fixed push/pull.
3. NetworkSolo the kick and bass. Ensure they're rhythmically aligned. Make space.(Advanced) Analyze bass MIDI and align kick notes to bass onsets.
4. NarrativeDraw velocity automation. Map song sections. Use ghost notes and dynamics.Use velocity variables that change per section. Add probabilistic ghost notes.
