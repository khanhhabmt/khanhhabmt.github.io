Music Notation Tools for Web Publishing

A Guide to Rendering Sheet Music and Drum Notation in Docusaurus

This document covers the major tools and libraries for writing and displaying music notation on a web-based blog or documentation site. Each section explains what the tool is, how it works, its strengths and weaknesses, and practical examples — with special attention to drum notation.

Overview Comparison​

1. abcjs​

What It Is​

A JavaScript library that renders ABC notation — a compact, text-based music format — directly in the browser as SVG. It can also play back the notation using Web Audio.

How It Works​

You write music as plain text using ABC syntax, and abcjs parses it into rendered sheet music on the page.

Installation​

npm install abcjs

Basic Example (Melody)​

X:1
T:Simple Scale
M:4/4
L:1/4
K:C
CDEF | GABc |

Drum Notation in ABC​

ABC has limited but functional percussion support using the %%MIDI drum directive:

X:1
T:Basic Rock Beat
M:4/4
L:1/8
%%MIDI channel 10
%%MIDI drum dddd 36 38 42 42 100 100 80 80
K:C perc
zB zB zB zB |

React Component Example​

import { useEffect, useRef } from 'react';
import abcjs from 'abcjs';

export default function ABCMusic({ notation }) {
  const ref = useRef();

  useEffect(() => {
    abcjs.renderAbc(ref.current, notation, {
      responsive: 'resize',
      staffwidth: 600,
    });
  }, [notation]);

  return <div ref={ref} />;
}

Strengths​

  • Very lightweight (~80KB gzipped)
  • Text-based — easy to write inline in Markdown/MDX
  • Built-in playback with synth module
  • Good for simple melodies, lead sheets, folk music

Weaknesses​

  • Drum notation is basic and unintuitive
  • No standard percussion staff rendering (5-line with x noteheads)
  • Limited multi-voice support
  • No proper beaming control for complex rhythms
  • ABC syntax is niche — fewer resources than standard notation

Best For​

Simple melodic examples, folk/traditional tunes, quick inline notation snippets.

2. VexFlow​

What It Is​

A low-level JavaScript library for rendering music notation as SVG or Canvas. It gives you full programmatic control over every element of the score.

How It Works​

You construct notes, voices, staves, and formatting objects in JavaScript code. VexFlow handles the engraving (rendering) to the page. It is a rendering engine, not a notation parser — you build the score in code.

Installation​

npm install vexflow

Basic Example (Melody)​

import { Renderer, Stave, StaveNote, Voice, Formatter } from 'vexflow';

const div = document.getElementById('output');
const renderer = new Renderer(div, Renderer.Backends.SVG);
renderer.resize(500, 200);
const context = renderer.getContext();

const stave = new Stave(10, 40, 400);
stave.addClef('treble').addTimeSignature('4/4');
stave.setContext(context).draw();

const notes = [
  new StaveNote({ keys: ['c/4'], duration: 'q' }),
  new StaveNote({ keys: ['d/4'], duration: 'q' }),
  new StaveNote({ keys: ['e/4'], duration: 'q' }),
  new StaveNote({ keys: ['f/4'], duration: 'q' }),
];

const voice = new Voice({ num_beats: 4, beat_value: 4 });
voice.addTickables(notes);

new Formatter().joinVoices([voice]).format([voice], 350);
voice.draw(context, stave);

Drum Notation in VexFlow​

VexFlow has native drum notation support with proper percussion clef and x-shaped noteheads:

import { Stave, StaveNote, Voice, Formatter } from 'vexflow';

const stave = new Stave(10, 40, 400);
stave.addClef('percussion').addTimeSignature('4/4');

// Drum map: hi-hat = g/5/x2, snare = c/5, kick = d/4
const notes = [
  new StaveNote({
    keys: ['g/5/x2', 'd/4'],  // hi-hat + kick
    duration: '8',
    stem_direction: 1,
  }),
  new StaveNote({
    keys: ['g/5/x2'],          // hi-hat only
    duration: '8',
    stem_direction: 1,
  }),
  new StaveNote({
    keys: ['g/5/x2', 'c/5'],  // hi-hat + snare
    duration: '8',
    stem_direction: 1,
  }),
  new StaveNote({
    keys: ['g/5/x2'],          // hi-hat only
    duration: '8',
    stem_direction: 1,
  }),
];

Strengths​

  • Full control over every visual element
  • Native percussion staff with x-noteheads, stems, beaming
  • Publication-quality SVG output
  • Active development and large community
  • Can render any notation complexity (polyrhythms, cross-staff, etc.)

Weaknesses​

  • Very verbose — a simple measure takes 20+ lines of code
  • No text-based input format (must be coded programmatically)
  • No built-in playback
  • Steep learning curve for complex scores
  • Hard to maintain large scores in code

Best For​

Custom interactive notation apps, programmatically generated exercises, situations where you need precise control over rendering. Good for drum notation if you build a helper layer on top.

3. LilyPond​

What It Is​

A free, open-source music engraving program. It compiles text input files into publication-quality PDF, SVG, or PNG output. Think of it as "LaTeX for music."

How It Works​

You write .ly files using LilyPond's text syntax, then run the lilypond command to produce output files. For a Docusaurus site, you pre-render notation to SVG/PNG images and include them in your posts.

Installation​

# macOS
brew install lilypond

# Ubuntu/Debian
sudo apt install lilypond

Basic Example (Melody)​

\version "2.24.0"
\relative c' {
  \time 4/4
  c4 d e f | g a b c |
}

Compile: lilypond --svg my_score.ly

Drum Notation in LilyPond​

LilyPond has first-class drum notation with \drummode:

\version "2.24.0"

\header {
  title = "Basic Rock Beat"
}

\drums {
  \time 4/4
  <<
    {
      % Hi-hat pattern (stem up)
      hh8 hh hh hh hh hh hh hh |
    }
    \\
    {
      % Kick and snare (stem down)
      bd4 sn bd sn |
    }
  >>
}

This produces a proper percussion staff with:

  • Hi-hat on the top line with x noteheads
  • Snare on the third space
  • Kick (bass drum) on the bottom space
  • Correct stem directions for layered voices

Built-in Drum Instruments​

bd  = bass drum          sn  = snare
hh  = hi-hat (closed)    ho  = hi-hat (open)
hhp = hi-hat (pedal)     cb  = cowbell
cymc = crash cymbal      cymr = ride cymbal
tomh = high tom          tomml = mid-low tom
toml = low tom           tommh = mid-high tom

Integration with Docusaurus​

Option A: Manual pre-rendering

  1. Write .ly files in a notation/ folder
  2. Run lilypond --svg notation/*.ly
  3. Copy SVGs to static/img/notation/
  4. Reference in MDX: ![Rock Beat](/img/notation/rock-beat.svg)

Option B: Build script Add a pre-build script to package.json:

{
  "scripts": {
    "notation": "cd notation && for f in *.ly; do lilypond --svg \"$f\"; done && cp *.svg ../static/img/notation/",
    "build": "npm run notation && docusaurus build"
  }
}

Strengths​

  • Best engraving quality of any free tool
  • Excellent drum notation with proper percussion conventions
  • Text-based source — version controllable with git
  • Handles complex scores: polyrhythms, tuplets, grace notes, multi-voice
  • Huge library of built-in percussion instruments
  • Output is static (SVG/PNG) — zero client-side JavaScript

Weaknesses​

  • Requires LilyPond installed on the build machine (and in CI)
  • No in-browser rendering — must pre-compile
  • Syntax has a learning curve
  • No interactive playback
  • Extra build step adds complexity

Best For​

Publication-quality drum notation, complex multi-voice percussion scores, print-ready sheet music. The gold standard for drum notation rendering.

4. Flat.io​

What It Is​

A cloud-based music notation editor with real-time collaboration and embeddable scores. Think "Google Docs for sheet music."

How It Works​

You create scores in the Flat.io web editor (GUI — no code required), then embed them in your site via iframe. The embedded player supports playback, transposition, and part selection.

Embedding in Docusaurus (MDX)​

<iframe
  src="https://flat.io/embed/YOUR_SCORE_ID?sharingKey=KEY&layout=track&themeMode=auto"
  width="100%"
  height="400"
  frameBorder="0"
  allowFullScreen
  allow="autoplay; midi"
/>

Drum Notation in Flat.io​

  • Full percussion staff editor with point-and-click input
  • Standard General MIDI drum map
  • Supports multiple percussion voices (hi-hat/snare/kick layering)
  • Playback uses realistic drum samples

Pricing​

PlanScoresFeatures
Free15 scoresBasic editing, embed, playback
PowerUnlimitedMusicXML import/export, advanced sharing
EducationUnlimitedClassroom features, assignments

Strengths​

  • No code needed — visual editor
  • Interactive embedded player with playback
  • Real-time collaboration
  • Excellent drum notation GUI
  • MusicXML import/export (interoperable with other tools)

Weaknesses​

  • Depends on Flat.io servers (if service goes down, embeds break)
  • Free tier limited to 15 scores
  • Iframe embeds add page weight and external requests
  • Less control over visual styling
  • Content lives on a third-party platform

Best For​

Interactive scores with playback, collaborative editing, when you prefer a GUI over text-based input.

5. MuseScore​

What It Is​

A free, open-source desktop application for writing music notation. Scores can be shared on musescore.com and embedded via iframe.

How It Works​

  1. Download and install MuseScore on your computer
  2. Create scores using the GUI editor
  3. Upload to musescore.com
  4. Embed in your site via iframe

Embedding in Docusaurus (MDX)​

<iframe
  src="https://musescore.com/user/YOUR_ID/scores/SCORE_ID/embed"
  width="100%"
  height="400"
  frameBorder="0"
  allowFullScreen
  allow="autoplay"
/>

Exporting for Static Use​

MuseScore can export to:

  • MusicXML — for use with other renderers (OSMD, VexFlow)
  • PDF/SVG — for static images in your blog
  • MIDI — for playback integration

Drum Notation in MuseScore​

  • Dedicated drum input mode with on-screen drum palette
  • Standard percussion staff
  • Supports drumline, kit, and orchestral percussion
  • Multi-voice layering (stems up/down)

Strengths​

  • Free and open-source desktop application
  • Most full-featured notation editor available for free
  • Excellent drum notation with dedicated input mode
  • Large community and plugin ecosystem
  • Export to many formats (MusicXML, PDF, SVG, MIDI, MP3)

Weaknesses​

  • Requires desktop app for editing (not web-based editing)
  • Embedding depends on musescore.com (external dependency)
  • Embedded player UI is controlled by MuseScore, not you
  • Upload to musescore.com makes scores semi-public

Best For​

Full-featured score editing when you want a desktop GUI, exporting to multiple formats, large or complex arrangements.

6. OpenSheetMusicDisplay (OSMD)​

What It Is​

A JavaScript library that renders MusicXML files in the browser as SVG. It is built on top of VexFlow but provides a higher-level API that works with standard MusicXML input.

How It Works​

You provide a MusicXML file (exported from MuseScore, Finale, Sibelius, Flat.io, etc.) and OSMD renders it in the browser. This bridges the gap between GUI editors and web rendering.

Installation​

npm install opensheetmusicdisplay

React Component Example​

import { useEffect, useRef } from 'react';
import { OpenSheetMusicDisplay } from 'opensheetmusicdisplay';

export default function MusicSheet({ xmlUrl }) {
  const ref = useRef();

  useEffect(() => {
    const osmd = new OpenSheetMusicDisplay(ref.current, {
      autoResize: true,
      drawTitle: true,
    });

    osmd.load(xmlUrl).then(() => osmd.render());
  }, [xmlUrl]);

  return <div ref={ref} />;
}

Usage in MDX​

import MusicSheet from '@site/src/components/MusicSheet';

<MusicSheet xmlUrl="/scores/rock-beat.musicxml" />

Drum Notation​

OSMD renders whatever the MusicXML contains, including percussion staves. The quality depends on the MusicXML source:

  • Export from MuseScore/Flat.io → renders correctly with percussion clef and x noteheads
  • Supports multi-voice percussion layouts

Strengths​

  • Renders standard MusicXML — works with any notation editor's export
  • Higher-level than raw VexFlow — less code to write
  • In-browser rendering — no build step
  • Active development with good documentation

Weaknesses​

  • Large bundle size (~500KB+ gzipped)
  • Requires MusicXML files (can't write notation as text)
  • Rendering quality slightly below LilyPond
  • Complex scores may render slowly

Best For​

Displaying MusicXML files exported from desktop editors, when you want browser rendering without writing notation in code.

Recommended Approach for Drum Blog​

For a Docusaurus blog focused on drum practice and education, consider this hybrid workflow:

Quick Inline Examples → abcjs​

For simple rhythm patterns and short examples within a blog post. You already have this installed.

import ABCMusic from '@site/src/components/ABCSheetMusic';

Here's a basic quarter-note groove:

<ABCMusic notation={`X:1\nM:4/4\nL:1/4\nK:C perc\nB,DBD|`} />

Detailed Drum Scores → LilyPond (pre-rendered SVG)​

For practice sheets, full drum parts, and anything requiring proper percussion notation with multiple voices.

Here's the full drum part for the verse:

![Verse drum part](/img/notation/verse-drums.svg)

Interactive Scores with Playback → Flat.io embed​

For exercises where the reader benefits from hearing the playback at different tempos.

<iframe src="https://flat.io/embed/..." height="300" width="100%" />

This gives you the best of all worlds: lightweight inline examples, high-quality static notation, and interactive playback — without overloading your site with heavy JavaScript bundles.
