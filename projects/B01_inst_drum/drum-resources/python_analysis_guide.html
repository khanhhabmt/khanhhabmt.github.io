Analyzing the Four Dimensions with Python

A Data Analyst's Toolkit for Drumming Performance

This document provides ideas, tools, and starter code for quantitatively analyzing the four dimensions of drumming performance using Python. This is a perfect application of your data analysis skills to music.

The Toolkit (Libraries to Install)​

# Core audio analysis
pip install librosa numpy scipy matplotlib

# Source separation (isolate drums from a mix)
pip install spleeter  # by Deezer

# Symbolic (MIDI) groove analysis
pip install GrooveToolbox mido

# Optional: Advanced beat/onset detection
pip install madmom

Dimension 1: The Grid (Precision Analysis)​

Goal​

Measure how consistently a drummer hits notes relative to a perfect metronomic grid. Calculate the "timing variance."

Method​

  1. Detect the onset (start time) of every drum hit.
  2. Detect the estimated beat locations (the "grid").
  3. Calculate the deviation of each onset from its nearest grid line.
  4. Generate statistics: Mean deviation, Standard Deviation, Max deviation.

Starter Code​

import librosa
import numpy as np
import matplotlib.pyplot as plt

# --- 1. Load Audio ---
# Use a solo drum recording or extract drums first (see Dimension 3)
audio_path = "your_drum_track.wav"
y, sr = librosa.load(audio_path, sr=None)

# --- 2. Detect Onsets (Drum Hits) ---
onset_frames = librosa.onset.onset_detect(y=y, sr=sr, units='frames')
onset_times = librosa.frames_to_time(onset_frames, sr=sr)

# --- 3. Track the Beat (The Grid) ---
tempo, beat_frames = librosa.beat.beat_track(y=y, sr=sr)
beat_times = librosa.frames_to_time(beat_frames, sr=sr)

print(f"Estimated Tempo: {tempo:.2f} BPM")
print(f"Detected {len(onset_times)} onsets and {len(beat_times)} beats.")

# --- 4. Calculate Deviation from Grid ---
deviations_ms = []
for onset_t in onset_times:
    # Find the nearest beat
    nearest_beat_idx = np.abs(beat_times - onset_t).argmin()
    nearest_beat_t = beat_times[nearest_beat_idx]
    
    # Calculate deviation in milliseconds
    deviation = (onset_t - nearest_beat_t) * 1000
    deviations_ms.append(deviation)

deviations_ms = np.array(deviations_ms)

# --- 5. Report Statistics ---
print(f"\n--- Dimension 1: Grid Precision Report ---")
print(f"Mean Deviation: {np.mean(deviations_ms):.2f} ms")
print(f"Std Deviation:  {np.std(deviations_ms):.2f} ms")  # Lower = More Precise
print(f"Max Deviation:  {np.max(np.abs(deviations_ms)):.2f} ms")

# --- 6. Visualize ---
plt.figure(figsize=(12, 4))
plt.hist(deviations_ms, bins=50, color='steelblue', edgecolor='black')
plt.axvline(0, color='red', linestyle='--', label='Perfect Grid')
plt.xlabel("Deviation from Grid (ms)")
plt.ylabel("Frequency")
plt.title("Distribution of Hit Deviations (Dimension 1: Grid)")
plt.legend()
plt.tight_layout()
plt.savefig("grid_analysis.png")
plt.show()

What to Look For​

  • Low Std Deviation (~5-15ms): Very precise, "tight" drummer.
  • High Std Deviation (>30ms): Either sloppy OR intentionally loose.
  • Mean Deviation near 0: Plays "in the center."
  • Consistent Positive/Negative Mean: See Dimension 2.

Dimension 2: Micro-Timing & Feel (Ahead/Behind Analysis)​

Goal​

Determine if the drummer consistently plays ahead of, behind, or on the beat.

Method​

This is the interpretation of the data from Dimension 1.

Starter Code (Continuing from above)​

# --- Dimension 2: Micro-Timing Feel ---

mean_dev = np.mean(deviations_ms)

print(f"\n--- Dimension 2: Micro-Timing Feel Report ---")
if mean_dev < -10:
    print(f"Feel: AHEAD of the beat (Avg: {mean_dev:.2f} ms early)")
    print("Interpretation: Driving, urgent, Stewart Copeland-esque.")
elif mean_dev > 10:
    print(f"Feel: BEHIND the beat (Avg: {mean_dev:.2f} ms late)")
    print("Interpretation: Laid-back, heavy, John Bonham-esque.")
else:
    print(f"Feel: ON the beat (Avg: {mean_dev:.2f} ms)")
    print("Interpretation: Solid, precise, Steve Gadd-esque.")

# --- Visualize Feel Over Time ---
# This shows if the feel changes throughout the song (e.g., behind in verse, ahead in chorus)
plt.figure(figsize=(14, 5))
plt.plot(onset_times, deviations_ms, marker='o', linestyle='-', alpha=0.7)
plt.axhline(0, color='red', linestyle='--', label='Perfect Grid')
plt.fill_between(onset_times, -10, 10, color='green', alpha=0.1, label='On the beat zone')
plt.xlabel("Time (s)")
plt.ylabel("Deviation (ms)")
plt.title("Micro-Timing Feel Over Time (Dimension 2)")
plt.legend()
plt.tight_layout()
plt.savefig("feel_over_time.png")
plt.show()

Advanced: Analyze by Drum Piece​

With source separation (see below), you can analyze the snare, kick, and hi-hat separately to see:

  • "Is the snare consistently behind but the hi-hat on the beat?" (Common in hip-hop/R&B)
  • "Does the kick push but the snare drag?" (Creates a specific tension)

Dimension 3: The Network (Drum-Bass Lock Analysis)​

Goal​

Measure the synchronization between the drum track and the bass track.

Step 1: Separate Drums and Bass​

Use Spleeter to isolate the drum and bass stems from a full mix.

from spleeter.separator import Separator

# This uses a pre-trained 4-stem model (vocals, drums, bass, other)
separator = Separator('spleeter:4stems')

audio_path = "full_song_mix.mp3"
output_path = "output/" # Spleeter will create subfolders

separator.separate_to_file(audio_path, output_path)

# Stems will be saved in:
# output/full_song_mix/drums.wav
# output/full_song_mix/bass.wav

Step 2: Analyze Correlation​

import librosa
import numpy as np
from scipy.signal import correlate

# --- Load Separated Stems ---
y_drums, sr = librosa.load("output/full_song_mix/drums.wav", sr=None)
y_bass, sr = librosa.load("output/full_song_mix/bass.wav", sr=sr)

# --- Get Onset Strength Envelopes ---
# These are curves that peak when a note starts
onset_env_drums = librosa.onset.onset_strength(y=y_drums, sr=sr)
onset_env_bass = librosa.onset.onset_strength(y=y_bass, sr=sr)

# Ensure same length
min_len = min(len(onset_env_drums), len(onset_env_bass))
onset_env_drums = onset_env_drums[:min_len]
onset_env_bass = onset_env_bass[:min_len]

# --- Calculate Cross-Correlation ---
# This measures how "aligned" the two signals are
correlation = np.corrcoef(onset_env_drums, onset_env_bass)[0, 1]

print(f"\n--- Dimension 3: Network (Drum-Bass Lock) Report ---")
print(f"Rhythmic Correlation (Drums vs. Bass): {correlation:.4f}")

if correlation > 0.7:
    print("Assessment: Excellent lock. The rhythm section is tight.")
elif correlation > 0.4:
    print("Assessment: Good lock. Some rhythmic interplay.")
else:
    print("Assessment: Loose lock. Rhythms are independent or conflicting.")

What to Look For​

  • Correlation > 0.7: Very tight lock. Kick and bass are likely playing in unison.
  • Correlation 0.4 - 0.7: Complementary but not locked. Bassist is adding counter-rhythms.
  • Correlation < 0.4: Independent or possibly poorly synchronized.

Dimension 4: The Narrative (Dynamics Analysis)​

Goal​

Measure the dynamic range and variation in a drum performance.

Method​

  1. Calculate the Root Mean Square (RMS) energy over time. RMS is a proxy for loudness.
  2. Analyze the variance. A monotone performance has low variance. A dynamic performance has high variance.
  3. Map the dynamic curve to song sections.

Starter Code​

import librosa
import numpy as np
import matplotlib.pyplot as plt

# --- Load Audio ---
y, sr = librosa.load("your_drum_track.wav", sr=None)

# --- Calculate RMS Energy (Loudness) Over Time ---
# frame_length and hop_length define the "window" size
rms = librosa.feature.rms(y=y, frame_length=2048, hop_length=512)[0]
times = librosa.frames_to_time(np.arange(len(rms)), sr=sr, hop_length=512)

# --- Normalize to 0-1 range ---
rms_normalized = (rms - rms.min()) / (rms.max() - rms.min())

# --- Report Statistics ---
print(f"\n--- Dimension 4: Narrative (Dynamics) Report ---")
print(f"Mean RMS (Normalized): {np.mean(rms_normalized):.3f}")
print(f"Dynamic Range (Max - Min): {np.max(rms_normalized) - np.min(rms_normalized):.3f}")
print(f"Dynamic Variance: {np.var(rms_normalized):.4f}")

if np.var(rms_normalized) < 0.01:
    print("Assessment: Flat dynamics. Performance is monotone.")
elif np.var(rms_normalized) < 0.03:
    print("Assessment: Moderate dynamics. Some variation across sections.")
else:
    print("Assessment: High dynamics. Strong narrative arc.")

# --- Visualize the Dynamic Curve ---
plt.figure(figsize=(14, 5))
plt.plot(times, rms_normalized, color='purple', alpha=0.8)
plt.fill_between(times, 0, rms_normalized, color='purple', alpha=0.3)
plt.xlabel("Time (s)")
plt.ylabel("Loudness (Normalized RMS)")
plt.title("Dynamic Curve Over Time (Dimension 4: Narrative)")
plt.ylim(0, 1.1)
plt.tight_layout()
plt.savefig("dynamic_curve.png")
plt.show()

Advanced: Detect Ghost Notes​

Ghost notes are characterized by their low velocity relative to surrounding notes.

# Conceptual approach for MIDI analysis with GrooveToolbox
from grooveToolbox import Pattern

# Load a MIDI drum loop
pattern = Pattern.from_midi("drum_loop.mid")

# Get velocities for the snare drum
snare_velocities = pattern.get_velocities(instrument='snare')

# Define "ghost notes" as hits below a threshold (e.g., 40% of max velocity)
threshold = 0.4 * max(snare_velocities)
ghost_notes = [v for v in snare_velocities if v < threshold]

print(f"Number of Ghost Notes: {len(ghost_notes)}")
print(f"Percentage of Ghost Notes: {len(ghost_notes) / len(snare_velocities) * 100:.1f}%")
