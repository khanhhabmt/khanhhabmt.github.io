The Neck as a Coordinate System

A pianist reads pitch off a one-dimensional row of keys: one note, one place. A guitarist reads it off a two-dimensional grid — string × fret — where the same note lives in several spots. That sounds like a disadvantage, but the grid has a superpower the keyboard lacks: shapes move. This file sets up the fretboard as a coordinate system so the rest of the folder (why EADGBE, and the circle of fifths on the neck) has a frame.

1. Two axes, two step sizes​

Every position on the neck is a coordinate (string, fret), and each axis adds a fixed number of semitones:

ALONG a string  (move up one fret):     +1 semitone      — always, everywhere
ACROSS strings  (move to the next):     +5 semitones     — a perfect fourth
                                         (EXCEPT G→B, which is +4, a major third)

So pitch is almost a simple linear function of the coordinate:

pitch(string, fret) ≈ open-string-pitch(string) + fret

The fret axis is perfectly uniform: one fret is one semitone at every point on the neck, no exceptions. That single fact is the whole reason the guitar feels the way it does.

2. Why uniform frets mean movable shapes​

Because the fret axis is uniform, any shape you learn is transposable by sliding it. A chord grip or scale pattern is just a set of (string, fret) offsets; move the whole set up two frets and every note rises exactly two semitones — you've transposed up a whole tone without changing the shape.

E-shape barre chord at fret 1 → F
                    at fret 3 → G      (same fingering, slid up 2 frets)
                    at fret 5 → A

Compare a piano: a C-major scale (all white keys) and a C♯-major scale (five black keys) have completely different physical shapes, because the keyboard's layout is irregular. The guitar's uniform fret axis means one shape = one sound-pattern, anywhere. This is why guitarists think in movable shapes and positions rather than absolute note names — the geometry does the transposing for them.

3. The catch: the across-string axis is not uniform​

The grid would be perfectly regular if every string were a fourth above the last. But standard tuning slips in one major third (between the G and B strings), so the across-string step is +5, +5, +5, +4, +5. Consequences:

  • Notes on the B and high-E strings are shifted one fret relative to where the all-fourths pattern would put them.
  • So a shape that crosses the G–B boundary bends — you nudge the fingering up a fret on the top two strings. Every guitarist internalizes this "kink" (it's the reason the same octave shape looks different depending on which strings it spans, and a big part of what the CAGED system is bookkeeping).

Why tolerate a broken axis at all? Because that major third is a deliberate trade that makes chords reachable — which is the whole subject of the next file.

4. The multiple-locations feature​

In this coordinate system the same pitch appears at several (string, fret) spots (e.g. the note E sits in half a dozen places). On a piano each note is unique; on a guitar it's redundant. That redundancy is a feature:

  • It lets you choose a spot for timbre (a note on a thick lower string sounds warmer than the same pitch high on a thin string — the acoustics at work).
  • It lets you keep a hard passage under one hand position by picking convenient duplicates.
  • It creates voicing options — the same chord can be grabbed in many shapes.

5. Takeaway​

  • The fretboard is a 2-D grid: (string, fret), with +1 semitone per fret (perfectly uniform) and +5 semitones per string (a fourth) — except the G→B major third.
  • The uniform fret axis is what makes shapes movable — the guitar's defining advantage over the irregular keyboard.
  • The one major third breaks the across-string axis, bending shapes over the B string — a deliberate cost, unpacked next.
